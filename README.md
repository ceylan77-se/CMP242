# Password Generator Project CMP242

Bu repo CMP242 dersi kapsamında geliştirdiğim Python çalışmalarını içermektedir.  
Ana proje bir **rastgele şifre üretme uygulamasıdır**.

## Ana Proje: Password Generator

`password_generator.py` dosyası, kullanıcının belirlediği uzunlukta rastgele ve güvenli şifreler üretir.

### Amaç
Güçlü şifre oluşturma mantığını öğrenmek ve Python'da string ve rastgele üretim konularını uygulamak.

### Çalıştırma

Terminal veya komut satırında:

```bash
python password_generator.py
